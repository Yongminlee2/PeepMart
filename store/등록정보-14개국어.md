플레이 콘솔에 언어별로 그대로 붙여 넣는다. 콘솔 **기본 언어는 영어(en)**.

> 글자 수 제한: 앱 이름 30자 · 간단한 설명 80자 · 자세한 설명 4000자. 아래는 전부 제한 안이다.
> **광고·인앱결제·무료·인터넷·개인정보 이야기는 한 줄도 없다** (common/traps/06-store-release.md).

## 한국어 (ko)

**앱 이름**
```
삐약마트 - 귀여운 편의점 타이쿤
```

**짧은 설명**
```
물건을 나르고 계산하며 나만의 귀여운 편의점을 키워 보세요!
```

**자세한 설명**
```
화면을 끌어 귀여운 점원을 움직이고, 작은 편의점을 동네 최고의 가게로 키워 보세요!

■ 직접 나르고, 직접 채우고
창고 상자 옆에 서면 상품이 머리 위로 착착 쌓이고, 진열대 옆에 가면 하나씩 날아가 채워져요. 캔음료, 도넛, 샌드위치, 아이스바, 케이크까지 10가지 상품을 들여올 수 있어요.

■ 계산대에 서면 자동 계산
손님이 줄을 서면 계산대 뒤에 서 주세요. 받은 돈은 계산대 옆에 지폐 더미로 쌓이고, 걸어가서 주우면 촤르르 들어와요.

■ 구매 칸으로 가게 키우기
바닥의 초록 칸에 서 있으면 돈이 들어가며 새 진열대, 알바, 더 빠른 신발, 더 넓은 가게가 열려요.

■ 알바를 뽑으면 손이 편해져요
계산 알바와 진열 알바가 내가 하던 일을 대신 해 줘요. 자리를 비운 사이에도 알바가 가게를 지켜요.

■ 손님을 행복하게
원하는 물건이 비어 있으면 손님이 말풍선을 띄우고 기다려요. 손님이 행복하면 별점이 오르고, 별점이 높을수록 손님이 더 많이 찾아와요.

■ 이런 분께 추천해요
• 귀엽고 아기자기한 게임을 좋아하는 분
• 틈틈이 짧게 즐길 게임을 찾는 분
• 아이와 함께 할 쉬운 경영 게임을 찾는 분

14개 언어를 지원해요.
```
