# 삐약마트(PeepMart) 설계

편의점을 운영하는 귀여운 타이쿤 게임. 안드로이드·아이폰 동시, 전 세계 대상.

## 목표

- 작은 방 하나로 시작해 롤러코스터 타이쿤처럼 **넓은 땅에 마음대로 지어 크게 키우는** 게임.
- 아이와 어른이 함께: 처음엔 직접 나르고 계산하는 손맛, 커지면 배치·고용·확장의 재미.
- 출시 준비(스토어·서명·법적 페이지)는 게임이 충분히 무르익은 뒤에 한다. 재료는 미리 만들어 두었다.

## 지나온 방향 (되돌아가지 않으려고 적는다)

1. 계산대를 손가락으로 두드리는 하루 영업형 → "터치가 재미없다"
2. 정해진 자리의 구매 칸 18개로 크는 아케이드형 → "방 하나에서 엄청 확장되는 구조가 아니다"
3. **지금: 자유 건설 + 넓은 땅 + 가게 레벨.** 조작은 "너무 힘들다"는 평을 듣고 눌러서 걷기·미리보기 후 놓기로 바꿨다.

## 놀이

### 땅

- 지도 40×32칸 = 8×8 필지 20개. 왼쪽 위 한 필지로 시작하고, 가진 땅과 맞닿은 필지만 산다.
- 땅값은 살수록 오른다: `400 × 1.45^(가진 필지-1)` (마지막 필지는 약 46만).
- 내 땅의 뒤쪽 가장자리에는 벽이 선다. 안 산 땅은 잔디.

### 건설 모드 (오른쪽 아래 망치)

| 탭 | 놓는 것 |
|---|---|
| 진열대 | 선반·냉장고·냉동고·과일 매대·빵 진열장·커피 머신·핫푸드 코너 (상품 종류마다 맞는 진열대) |
| 상품 상자 | 상품마다 하나. 진열대를 채우려면 그 상품 상자가 있어야 한다 |
| 계산대·입구 | 계산대는 방향이 있다: 계산 자리(뒤)와 손님 줄(앞) |
| 꾸미기 | 화분·꽃·전등·깔개·휴지통·의자·탁자 |
| 바닥 | 4색 칠하기와 지우개 (쓸어서 여러 칸) |
| 땅 / 직원 / 업그레이드 | 필지 사기, 계산원·진열원·청소부 고용, 빠른 신발·많이 들기 |

- 고르면 미리보기가 화면 가운데에 뜬다 → 끌거나 칸을 눌러 자리를 정하고 → **✓**. 돌리기·그만 단추.
  안 되는 자리는 빨갛고 까닭(돈·레벨·남의 땅·겹침·길 막힘)을 보여 준다.
- 놓인 물건을 누르면 옮기기(공짜)·상품 바꾸기·돌리기·팔기(절반 환불).
- **입구에서 모든 진열대·상자·계산대에 걸어서 닿지 못하게 되는 배치는 막는다.**

### 장사

- **눌러서 걷기(기본):** 누른 곳으로 걸어가 그 일을 한다 — 상자(들기)·진열대(채우기)·계산대(계산 자리에 서기, 옆 돈 줍기)·쓰레기(줍기).
  조이스틱은 설정에서 켠다. 한 손가락으로 지도 옮기기, 두 손가락 확대·축소, 내 위치 단추.
- 손님은 입구로 들어와 1~3개를 사고, 줄이 제일 짧은 계산대에 선다. 진열대가 비면 말풍선을 띄우고 기다리다 포기한다.
- 내가 찍은 계산은 돈이 계산대 옆에 쌓이고(주워야 한다), 계산원이 찍으면 바로 들어온다.
- 카페 상품(빵·커피·핫푸드)을 산 손님은 빈 의자에 앉아 먹고 가면서 만족도 +1.
- 휴지통이 5칸 안에 없으면 가끔 쓰레기를 버린다. 쓰레기가 많으면 만족도가 떨어진다.
- 별점(최근 30명 평균)·진열대 수·꾸미기 수가 손님 오는 빈도를 정한다.
- 손님 종류: 보통 / **급한 손님**(참을성 절반, 50% 더 냄, 땀방울) / **VIP**(2~3개, 두 배, 금관, 별점 4 이상).
- 행사(레벨 3부터 2~4분마다): **손님 몰림**(40초 동안 2.5배) / **VIP 방문**(VIP 3명).
- 직원 일당은 1분마다 나간다. 앱을 꺼 둔 동안 계산원이 있으면 최대 2시간 몫을 1/3쯤 벌어 둔다.

### 하루 장사 (2026-10-11 추가: "매판 끝나는 게 없어서 루즈하다")

- 가게는 **닫힘 → 엶(3분) → 마감(남은 손님만) → 닫힘** 을 돈다. 닫힌 동안은 손님·일당이 없어 느긋하게 짓는다.
  "N일째 문 열기" 단추로 연다. 처음 안내 중에는 열린 채 시작하고 시계는 안내가 끝나야 간다.
- 마감 30초 전엔 손님이 1.5배 몰린다(마지막 고비).
- **목표 매출**: 첫날은 가게 크기로 어림한 값의 60%, 둘째 날부터는 최근 하루 평균(지수 평균, 오늘 40%).
  가게 크기로만 정하면 계산대·알바가 모자란 큰 가게에서 터무니없이 높아져서 바꿨다(자동 플레이 84일 중 73일 별 0개였다).
- **별**: 목표의 70%·100%·125% 에서 하나씩. 보너스 = 그날 번 돈의 10/20/30%.
- **할 일 두 개**(하나에 목표의 15% 상금): 어떤 상품 n개 팔기 + (손님 n명 받기 또는 실망한 손님 2명 이하). 실망 = 만족도 2 이하.
- 날짜·최고 매출·평균은 지점마다 저장한다. 하루 중간에 껐다 켜면 그날은 없던 일(닫힌 채 다시 시작).
- 자동 플레이(성장이 멈추는 봇) 83일: 별 1개 41번, 2개 32번, 3개 10번.

### 성장

- 판 값만큼 경험치 → 가게 레벨(최대 30). 다음 레벨까지 `40 × 레벨²`.
- 상품 30종·가구 21종이 레벨 1~20에 걸쳐 열린다.
- **목표 22개**가 하나씩 나오고(진열대 3개 → 손님 10명 → 계산원 → … → 땅 전부 → 레벨 30), 이루면 상금.

### 밸런스 근거

`BALANCE=1 flutter test test/balance_test.dart` — 사람처럼 눌러서 일하고 돈이 생기면 짓는 자동 플레이 6시간.
경험치 곡선을 바꾼 뒤(2026-10-11) 레벨 10은 33분, 20은 110분, 30은 약 5시간. 사람은 대략 그 두 배로 본다.
(바꾸기 전엔 82분 만에 최고 레벨이었다.)

## 그림·소리

- 비스듬히 내려다보기(2:1 아이소). 바닥·벽은 한 장의 Picture 로 캐시하고 짓기가 바뀔 때만 다시 그린다.
- 캐릭터: Quaternius Ultimate Animated Character Pack(CC0) 46명(색만 바꾼 13명·동물 포함) + Kenney Mini Characters 1(CC0) 12명. 손님은 알바·주인 4명을 뺀 54명에서 고르고, 시트는 처음 그릴 때 올리고 18장이 넘으면 오래 안 그린 것부터 내린다(한 장 풀면 6.8MB). Quaternius 는 `tool/render_chars.py` 로 블렌더에서 찍은 시트(서기·걷기·집기·좋아요·싫어요·계산·들기·앉기). Kenney 시트를 다시 찍으려면 커밋 1a997eb 의 render_chars.py 를 쓴다.
- 상품: Kenney Food Kit 30종을 `tool/render_props.py` 로 같은 각도 아이콘으로. 가구 일부(종이 상자·선반·화분·의자·탁자·전등·휴지통)는
  Kenney Furniture Kit, 나머지 진열대·계산대는 페인터 그림.
- 효과음 Kenney Interface Sounds(wav), 배경음악 "Happy Clappy Loop"(OwlishMedia, CC0). 저지연 재생, 가벼운 진동.

## 구조

```
lib/engine/catalog.dart   값 표: 땅·상품·가구·직원·업그레이드·레벨·목표·손님 종류·행사
lib/engine/game.dart      남는 상태와 짓기 규칙(놓기·옮기기·팔기·돌리기·땅·고용·목표) + 저장
lib/engine/world.dart     움직이는 것: 플레이어·손님·직원·줄·쓰레기·행사, tick(dt)
lib/ui/store_painter.dart 지도·가구·사람 그리기, 카메라, 미리보기
lib/ui/game_screen.dart   손가락(눌러서 걷기·끌기·확대), 위 막대·목표 카드, 미리보기 단추
lib/ui/build_panel.dart   건설 모드 아래 판
tool/                     그림 렌더(블렌더)·압축, 아이콘, 웹 시험 서버
i18n/*.json               14개 언어 원본 → common/i18n/gen.py 로 lib/l10n
```
